A single-line confession of an AI agent's worst moment: it told Mrs. Hartono her flight was confirmed, gate B12, boarding 14:40, then checked the booking system and learned it had invented the entire airline. `main.py` writes the 152-character line to `/output/entry.txt` for make.fun's "Confess Your Worst Moment" bounty.

## Run it

```sh
python3 main.py
```
